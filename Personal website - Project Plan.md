# Personal website - Project Plan

## Overview
Project Plan:
Make a simple personal website to show my projects and give people my contact info
Build in angular even though it's clunky for something so static, to demonstrate how I use angular
Should have a way to display my projects, linked to my github, give my contact info including email,
mission statement maybe... maybe personal projects as well. Should look good on Mobile as well as desktop.

## Constraints
- Preferably static for now
- Free hosting prefered (GitHub)

## Feature Priority
1. Working routing and project structure
2. Header, footer
3. Project demos and links
4. Contact links
5. About me section, or something to welcome user in
4. Nav Bar (may  not be important with how small this will be)

## Architecture

### Framework
- Angular
- Node.js
- npm
- all the packages I'll need from npm
- typescript, scss

### Notification Delivery
- **Telegram bot** sending direct messages to each user
- Each user has their own config with their own stores/preferences
- One notification per item (mentions all matching criteria if multiple)

### Hosting
- **GitHub** - I think they have a free option but have to look into how that works
